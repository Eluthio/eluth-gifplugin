# GIF Picker — Eluth Official Plugin

Search and insert GIFs from Tenor and Giphy directly into any chat channel.

## Setup

In your community server's admin panel → **Plugins → GIF Picker → Settings**:

| Field | Where to get it |
|-------|----------------|
| **Tenor API Key** | [tenor.com/gifapi](https://tenor.com/gifapi) — free |
| **Giphy API Key** | [developers.giphy.com](https://developers.giphy.com) — free tier |

You need at least one key. Both can be configured to give users a provider choice.

## Usage

Once enabled, a **GIF** button appears in the chat input bar. Click it to open the picker, search, and click any GIF to insert it into your message.
